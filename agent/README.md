# Local Modem Agent

این پوشه برای برنامه Agent محلی در نظر گرفته شده است. Agent روی دستگاهی اجرا می‌شود که به مودم TFi60-S1 در شبکه LAN دسترسی دارد.

در نسخه فعلی، Agent هنوز پیاده‌سازی نشده است. قبل از فعال‌سازی باید:
- احراز هویت امن سرور و Agent طراحی شود.
- رمز عبور مودم در فایل عمومی یا مخزن کد قرار نگیرد.
- ارتباط Agent با سرور از طریق HTTPS برقرار شود.
- از تکرار ناخواسته پیامک در زمان retry جلوگیری شود.
