# SMS Gateway - نسخه 1.1

این نسخه شامل اتصال PDO به MySQL و داشبورد اولیه فارسی است.

## به‌روزرسانی روی XAMPP

1. از پوشه فعلی `SMS-Gateway` یک نسخه پشتیبان بگیر.
2. فایل ZIP را Extract کن.
3. فایل‌های نسخه جدید را روی پوشه قبلی کپی و جایگزین کن.
4. تنظیمات اتصال دیتابیس را در `config/database.php` بررسی کن.
   - دیتابیس: `sms_gateway`
   - کاربر پیش‌فرض XAMPP: `root`
   - رمز پیش‌فرض خالی است؛ اگر رمز تعیین کرده‌ای، آن را وارد کن.
5. Apache و MySQL را روشن نگه دار.
6. این آدرس را باز کن: `http://localhost/SMS-Gateway/public/`

## امکانات این نسخه

- اتصال امن‌تر PDO با prepared/exception mode
- خواندن آمار پروژه‌ها و پیامک‌ها از دیتابیس
- نمایش وضعیت اتصال MySQL
- داشبورد فارسی و واکنش‌گرا

این نسخه هنوز ورود مدیر، مدیریت پروژه‌ها، API عملیاتی و اتصال مودم را ندارد. منوهای غیرفعال صرفاً جایگاه ماژول‌های بعدی هستند.
