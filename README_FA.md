# SMS Gateway

پنل پیامکی مستقل و قابل اتصال به چندین پروژه از طریق REST API.

## امکانات موجود

- داشبورد مدیریتی فارسی و واکنش‌گرا
- ثبت و مدیریت پروژه‌های متصل
- ساخت و ابطال کلیدهای API
- API ثبت پیامک و قراردادن آن در صف پردازش
- مشاهده، جستجو و فیلتر صف پیامک
- نمایش تاریخ‌های پنل به تقویم شمسی با ارقام فارسی
- اتصال PDO به MySQL

## نیازمندی‌ها

- PHP 8.0 یا بالاتر (پیشنهادی)
- MySQL 5.7 یا بالاتر / MariaDB سازگار
- Apache و افزونه‌های PDO MySQL و mbstring در PHP
- XAMPP برای اجرای محلی

## نصب روی XAMPP

1. از پوشه فعلی پروژه یک نسخه پشتیبان تهیه کنید.
2. فایل ZIP را استخراج کنید.
3. پوشه `SMS-Gateway` را در مسیر `C:\\xampp\\htdocs\\` قرار دهید.
4. در phpMyAdmin دیتابیس `sms_gateway` را بسازید.
5. فایل `config/database.php.example` را به `config/database.php` کپی کنید.
6. اطلاعات اتصال دیتابیس را در `config/database.php` وارد کنید.
7. جداول موردنیاز را مطابق ساختار دیتابیس فعلی پروژه ایجاد کنید. اگر دیتابیس قبلاً ساخته شده است، فایل `database/schema.sql` را بدون بررسی تطابق اجرا نکنید؛ اجرای دوباره اسکریپت روی دیتابیس موجود توصیه نمی‌شود.
8. Apache و MySQL را در XAMPP روشن کنید.
9. آدرس زیر را باز کنید:

`http://localhost/SMS-Gateway/public/`

## تنظیم دیتابیس

فایل تنظیمات واقعی `config/database.php` عمداً در مخزن قرار نمی‌گیرد تا رمز عبور و اطلاعات اتصال منتشر نشوند. نمونه تنظیمات در `config/database.php.example` قرار دارد.

## API ثبت پیامک

مسیر:

`POST /SMS-Gateway/public/api/v1/send.php`

درخواست باید شامل هدر `Authorization: Bearer YOUR_API_KEY` و بدنه JSON با فیلدهای `phone` و `message` باشد.

ثبت موفق درخواست به معنی ارسال واقعی پیامک نیست؛ پیام ابتدا در دیتابیس و صف ذخیره می‌شود. ارسال واقعی تا زمان تکمیل Worker و اتصال تأییدشده مودم فعال نیست.

## تقویم شمسی

تاریخ و ساعت در صفحات پنل با کلاس مشترک `app/Services/JalaliDate.php` به تقویم شمسی تبدیل می‌شود. تاریخ‌ها در دیتابیس به فرمت استاندارد میلادی باقی می‌مانند تا مرتب‌سازی و پردازش صحیح باشد.

## نکات امنیتی

- فایل `config/database.php` و کلیدهای API را در GitHub منتشر نکنید.
- پنل مدیریتی را بدون احراز هویت و HTTPS در اینترنت عمومی قرار ندهید.
- رابط مدیریتی مودم را مستقیماً در اینترنت منتشر نکنید.
- فایل آزمایشی `public/test.php` را پیش از استقرار عملیاتی حذف یا محدود کنید.

## وضعیت توسعه

صفحه داشبورد، مدیریت پروژه‌ها، مدیریت کلیدهای API، ثبت API و مشاهده صف پیاده‌سازی شده‌اند. پردازشگر صف، اتصال عملیاتی مودم، دریافت پیامک و Local Agent هنوز نیازمند توسعه و آزمون مستقل هستند.
